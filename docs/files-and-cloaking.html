Files and cloaking

The Explorer shows what changed since the last sync and offers the site's actions on its files; the Remote Files view shows the server's side.

Explorer marks

Marks on files of the active site
MarkMeans
⊘, dimmedCloaked: never synchronized.
↑Changed or added since the last sync. Put uploads it.
!, warning colourChanged locally and on the server since the last sync. Synchronize to choose which copy to keep. The colour carries up to its folders.

Every mark has a tooltip. They show only for the active site, and only once it has been synchronized, so a new site is not covered in arrows. They come from the records of the last sync and the last preview, worked out again after every sync and on save, never on a timer and never by asking a server. syncServers.decorations.enabled turns them off.

Explorer and editor menus

When the open workspace is inside the active site's local folder, the Explorer's context menu offers Put, Get, Compare with Remote (files only), Synchronize..., Cloak and Uncloak, for one file or several chosen together. The editor's context menu and its tab's offer Put, Get and Compare with Remote. Every one of them is also in the Command Palette, acting on the file in the editor.

Cloak and Uncloak

Cloak adds the chosen files and folders to the site's cloaked paths: from then on they are never scanned, listed, transferred or deleted, on either side. Uncloak takes them out again; run from the Command Palette with no file open, it lists the cloaked paths to choose from. A file can also be cloaked by a pattern, such as .psd, by a global pattern, or by a cloaked folder above it; Uncloak says which, and points to the patterns in Site Settings or to Global Cloaking Patterns.

Global cloaking patterns

Files that belong to no site, such as .git/, node_modules/ or Thumbs.db, can be cloaked once for every site. Sync Servers: Global Cloaking Patterns... lists them: Add Patterns... takes new ones, separated by spaces, and choosing a pattern removes it after a question. Every site uses the global patterns before its own, so a site's !pattern brings back what a global pattern cloaks, and a site can turn them off with Use global patterns in Site Settings. They are kept in the list of sites, so sync-servers cloak --global on the command line changes the same patterns, and the Explorer marks follow at once.

The Remote Files view

The Remote Files view lists the active site's Remote server, one folder at a time as you open them, so a large server is never listed whole. Files changed or added on the server since the last sync carry ↓; cloaked ones carry ⊘. Clicking a file opens it read-only.

Actions in the Remote Files view
ActionDoes
Open Read-OnlyThe server's copy in a read-only editor.
Compare with RemoteThe server's copy beside the local file.
GetDownloads the file or folder, through the same plan and guards as Synchronize.
Cloak, UncloakAs in the Explorer.
Delete on ServerRemoves one file from the server after a question, and keeps the local copy. Refused at the top of a server unless the server allows deletes there.
Refresh Remote FilesLists the open folders again.

The view keeps one connection, closed after two minutes unused or when the active site changes.
