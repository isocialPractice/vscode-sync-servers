Sync Servers for VS Code

Keep a site's local folder and its servers in step from VS Code, the way Dreamweaver's Synchronize does: sites, servers, cloaking, and a preview of every file that would change before anything moves.

Early alpha. Everything on these pages works today, and details may still change before 1.0.0. Try it on a copy of a site first.

What it does

  • Sites and servers. A site is a local folder and its servers over SFTP, FTPS, FTP, or a local or network folder. One server holds the Remote role for synchronizing; another may hold the Testing role.
  • A preview of every change. Synchronize lists only the files that differ, grouped by what will happen to each, with a checkbox on every row. Nothing moves until you choose Synchronize Checked Files.
  • A memory of the last sync. A file changed on both sides since the last sync waits for your decision instead of being overwritten.
  • The Explorer knows. Changed files carry an arrow, cloaked files are dimmed, and Put, Get, Compare, Cloak and Uncloak are in the context menu.
  • Upload on save. A saved file can go straight to the Testing server, unless it is cloaked or sensitive.
  • One list of sites. The extension shares its sites with the sync-servers command line and runs the same engine.

Install

It needs VS Code 1.101 or later, on Windows, macOS or Linux. Alphas are published as .vsix files on the releases page, not on the Marketplace.

  1. Download vscode-sync-servers-<version>.vsix from the latest release. Check the download if you like.
  2. In VS Code, open the Extensions view, choose ... at its top, then Install from VSIX..., and pick the file.

Or from a terminal:

code --install-extension vscode-sync-servers-1.0.0-alpha.0.5.0.vsix

The views at a glance

The Sync Servers icon in the activity bar, two stacked servers with arrows between them, opens three views:

The views of the Sync Servers container
ViewShows
SitesEvery site with its servers and their Remote and Testing roles. It starts with an Add Site button.
Remote FilesThe files on the active site's Remote server, one folder at a time.
Sync PreviewWhile a synchronization waits for you: each file that would change, grouped by what will happen to it.

The status bar shows the active site and its Remote server, such as My Site: Production, and counts files during a run.
