Site Settings

Dreamweaver's Site Setup as a form in the editor area: the categories on the left, the form of the chosen one on the right, and Revert, Cancel and Save below. Open it with Site Settings on a site in the Sites view, from the status bar menu, or from the Command Palette.

How editing works

  • The form edits a draft. Nothing reaches the list of sites until Save, or Ctrl+S (Cmd+S on macOS).
  • Revert puts the saved settings back. Cancel closes the form, and asks first when there are changes.
  • Save checks the whole site with the engine's own rules. Each problem is shown under the field it belongs to and read out, and the category or server holding it is marked.
  • If the command line changed the site while the form was open, Save asks whether to save over that change or reload the form with it.
  • Passwords are never typed into the form. Set Password... asks in VS Code's own password box, and the form shows only Saved or Not saved.

Site

The Site category
FieldHolds
Site nameThe name you know the site by, such as My Site, different from your other sites ignoring case.
Local site folderThe folder on this computer that holds the site. Browse... opens the folder picker.

Servers

A table of the site's servers with their host and protocol. The Remote column chooses the server Synchronize uses; the Testing column chooses the server that receives uploads on save, and its last row, No Testing server, clears it. Choose a row with the radio button in its first column, then Add, Edit, Duplicate, Remove or Test. Server changes are saved with the site, so Revert brings back a removed server until you save.

The Basic tab

Basic server fields
FieldHolds
Server nameUnique within the site. Add Site names a server after its host, such as sftp.example.com; rename it here, such as Production.
ProtocolSFTP, FTPS with explicit or implicit TLS, FTP, or a local or network folder. The fields the protocol does not use are hidden.
Host and PortThe FTP or SFTP host your hosting panel shows, such as sftp.example.com; leave the port empty for the usual one. host:port typed in Host moves the port into Port when you test, browse or save.
UserSuch as demo-user. Many hosts name FTP accounts in full, such as demo-user@example.com.
Sign in withSFTP only: a password, a private key file, or the SSH agent. A key file is used where it is and never copied.
Allow plain FTPFTP only, and needed for it: plain FTP sends the password and files in clear text.
Save passwordKeeps the password in VS Code's secret storage; without it you are asked each time. Set Password... and Forget Password act on the saved server.
Root directory, or FolderWhere the site is published, such as /var/www/my-site; for a local or network folder, the folder itself. Browse... connects and lists the folders on the server, starting where your account opens: Use This Folder picks the one shown, .. goes up, and a typed path goes straight there. Choosing / asks whether synchronizing may delete files there.

Test connects with the values the form shows, saved or not, signs in, checks that the root directory exists, and shows the result under the button. What the connection decides, such as another host the certificate covers or a host key you trusted, is written into the form; Save keeps it. A saved password is sent only while Protocol, Host, Port and User are the ones it was saved for; otherwise you are asked for it.

Cloaking

Cloaked files and folders are never scanned, listed, transferred or deleted, on either side. Enable cloaking turns them all on or off, the global patterns included. Use global patterns makes the site use the global cloaking patterns before its own; it is on unless you turn it off. Patterns go one per line, or separated by spaces:

Cloaking patterns
PatternCloaks
.psdEvery file whose name ends in .psd.
archive*Any file or folder whose name starts with archive, at any depth.
node_modules/Every folder of that name, with its contents.
/drafts/The drafts folder at the top of the site only.
!keep.psdBrings back a file an earlier pattern cloaked.

As you type, the form counts the files and folders the patterns, the global ones included, cloak in the local folder. Below, Global patterns lists the patterns every site uses, with Edit Global Patterns..., and Cloaked paths lists the files and folders cloaked one by one with Cloak in the Explorer, each with Uncloak.

Security

Hold back sensitive files lists matching files unchecked in the preview, so they move only when you check them. Also hold back adds your own patterns to the built-in list, which Always held back shows: .env, private keys, and version-control and credential folders among them.
